# Developer Portfolio Starter

A responsive one-page portfolio starter using HTML, CSS and JavaScript.

## Sections
- Introduction
- About
- Skills
- Selected projects
- Contact links

## Before publishing
Replace sample text and project descriptions with your own accurate information. Add only skills, certificates and projects you can explain. Add your real professional contact links; do not publish private contact details.

## Run
Open `index.html` in a browser. You can publish the repository with GitHub Pages from repository Settings → Pages.
